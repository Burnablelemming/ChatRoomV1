# ChatRoomV1
Chat room project for CS 4850 Computer Networks. Let's hope I remember how to code when making this project.

### Setup
1. Clone the repository to your local machine.
2. Ensure you have visual studio desktop c++ development installed.
3. Open the solution file in Visual Studio.
4. Build the project to restore any necessary dependencies.
5. If build fails, ensure you have the correct MSVC build tools installed and that your environment variables are set correctly.

### Running the Application
1. After building the project, run the application from Visual Studio or execute the generated executable file.
